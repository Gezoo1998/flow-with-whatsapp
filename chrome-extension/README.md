# 🧩 دليل تثبيت إضافة CenterFlow لأتمتة الواتساب (Chrome Extension V3)

تتميز هذه الإضافة بأنها تعمل كـ "جسر أوتوماتيكي ذكي" بين لوحة تحكم النظام (Next.js) وتبويب واتساب ويب المفتوح بالفعل على متصفحك لإرسال نتائج وتقارير الطلاب تلقائياً 100% وبدون أي سيرفرات مدفوعة.

---

## 🚀 خطوات التثبيت في المتصفح (Developer Mode)

1. **افتح متصفح جوجل كروم (Google Chrome)**.
2. اذهب إلى صفحة الإضافات عبر كتابة هذا الرابط في شريط العنوان:
   `chrome://extensions/`
3. قم بتفعيل **"وضع المطور" (Developer Mode)** من المفتاح الموجود بالزاوية العلوية (يمين أو يسار حسب لغة المتصفح).
4. اضغط على زر **"تحميل إضافة غير محزومة" (Load Unpacked)**.
5. حدد مجلد **`chrome-extension`** الموجود داخل جذر مشروع **CenterFlow**.
6. ستظهر لك إضافة **CenterFlow WhatsApp Automation Engine** في قائمة الإضافات بنجاح! 🎉

---

## 📌 كيفية الاستخدام
1. افتح موقع **[web.whatsapp.com](https://web.whatsapp.com)** في تبويب بالمتصفح وقم بتسجيل الدخول برقم الواتساب الخاص بالسنتر.
2. افتح صفحة **أتمتة الواتساب** في نظام CenterFlow.
3. ستلاحظ تغير بادج حالة الإضافة تلقائياً إلى: **`إضافة Chrome متصلة وجاهزة 🧩✅`**.
4. اختر المجموعة والتسميع/الامتحان ثم اضغط على زر **«بدء الإرسال الآلي بواسطة إضافة Chrome 🚀»**.
