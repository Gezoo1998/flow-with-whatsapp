ميزة قارئ الباركود (Barcode Scanner)

دراسة تفصيلية وسيناريوهات التنفيذ لأبلكيشن FlowCenter بالعامية المصرية 🇪🇬

📷

المسح عن طريق كاميرا الموبايل / التابلت

السيناريو ده بيعتمد بالكامل على الكاميرا المدمجة في الموبايل أو التابلت بتاع السكرتيرة أو المدرس. بنفتح الكاميرا جوة المتصفح (Webcam) ونقعد نلقط فريمات ونحللها لحظة بلحظة عشان نطلع كود الطالب.

درجة الصعوبة البرمجية (Complexity) متوسطة إلى مرتفعة (7 / 10)

👍 المميزات

مش محتاج تشتري أي جهاز إضافي. أي موبايل فيه كاميرا هيشتغل عادي جداً، ومناسب لو المدرس بيتحرك بين الطلبة في القاعة.

👎 العيوب والتحديات

بيسحب بطارية جامد، وبيعتمد على جودة الكاميرا والإضاءة المحيطة. لو الإضاءة ضعيفة أو الكود مهزوز، هيتأخر في القراية.

📱 تجربة المستخدم (UX)

لازم السكرتيرة توافق على صلاحيات الكاميرا في كل مرة، وتستنى الكاميرا تعمل فوكس (Autofocus) على الباركود.

المكتبة المقترحة للتنفيذ في Next.js:

هنستخدم مكتبة html5-qrcode لأنها خفيفة وبتدعم الـ React كويس جداً.

tsximport { Html5QrcodeScanner } from 'html5-qrcode';
import { useEffect } from 'react';

export default function CameraScanner({ onScanSuccess }) {
  useEffect(() => {
    const scanner = new Html5QrcodeScanner("reader", {
      fps: 10, 
      qrbox: { width: 250, height: 250 }
    }, false);

    scanner.render((decodedText) => {
      onScanSuccess(decodedText);
      scanner.clear(); // إيقاف الكاميرا بعد القراءة الناجحة
    }, (error) => {
      // خطأ في فك الشفرة (بيحصل مع كل فريم مش واضح)
    });

    return () => scanner.clear();
  }, []);

  return <div id="reader" style={{ width: '100%' }}></div>;
}

استخدام جهاز قارئ الباركود الخارجي (USB / Bluetooth)

هنا السكرتيرة بتستخدم مسدس باركود لاسلكي (Bluetooth) أو بسلك متوصل بالموبايل/الكمبيوتر عن طريق وصلة OTG. الجهاز ده بيشتغل كأنه كيبورد إضافي بالظبط (Keyboard Emulator)؛ أول ما بيشوف الباركود، بيكتب الحروف بتاعته بسرعة خارقة ويدوس Enter في أجزاء من الثانية.

درجة الصعوبة البرمجية (Complexity) سهلة جداً (2 / 10)

👍 المميزات

سرعة خرافية (أقل من 50 مللي ثانية). دقة 100% حتى لو الإضاءة ضلمة أو الباركود مطبوع بجودة رديئة. مش بيستهلك بطارية الموبايل نهائي.

👎 العيوب والتحديات

بيحتاج تكلفة إضافية لشراء مسدس الباركود (أسعارهم بتبدأ من 300-500 جنيه مصري للأجهزة السلكية البسيطة).

📱 تجربة المستخدم (UX)

ممتازة ومريحة جداً للسكرتارية اللي واقفين على مكتب ثابت. مجرد تك واحدة بتسجل حضور الطالب وتدفع الاشتراك فوري.

طريقة البرمجة الفائقة في Next.js (بدون مكتبات):

هنعمل Event Listener عالمي (Global Keydown listener) يلقط الحروف السريعة ويفلتر لو هي جاية من جهاز الباركود.

typescriptimport { useEffect, useRef } from 'react';

export function useHardwareScanner(onScan: (code: string) => void) {
  const buffer = useRef('');
  const lastKeyTime = useRef(0);

  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      const currentTime = Date.now();
      
      // لو الفرق بين الضغطات سريع جداً (أقل من 30 مللي ثانية) يبقى ده جهاز باركود مش إنسان بيكتب
      const isFast = currentTime - lastKeyTime.current < 30;
      lastKeyTime.current = currentTime;

      if (e.key === 'Enter') {
        if (buffer.current.length > 2) {
          onScan(buffer.current);
        }
        buffer.current = ''; // تصفير البافر
        return;
      }

      // إضافة الحرف للبافر
      if (e.key !== 'Shift') {
        if (isFast || buffer.current.length > 0) {
          buffer.current += e.key;
        } else {
          // لو الكتابة بطيئة، بنصفر البافر عشان نضمن إنه مش إدخال يدوي من الكيبورد العادية
          buffer.current = e.key;
        }
      }
    };

    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [onScan]);
}

التوصية النهائية لمشروع FlowCenter (الخلاصة)

بعد دراسة طبيعة الشغل في مراكز الدروس الخصوصية في مصر، بننصح بـ **دمج الطريقتين معاً** كالتالي:

🎯 الخطة المثالية للـ Implementation:

  • الاعتماد الأساسي (للسكرتيرة على المكتب): جهاز الباركود الخارجي (Hardware Scanner). نوصل المسدس بالكمبيوتر أو التابلت. ده هيخلّص طابور الطلبة في ثواني بدون تعليق الكاميرا أو طلب صلاحيات.
  • الخطة البديلة (للمدرس أو المساعد المتحرك): كاميرا الموبايل. نعمل زرار صغير اسمه "فتح الكاميرا للمسح" يشتغل لو السكرتيرة حابة تتحرك وسط القاعة تسجل غياب سريع.
  • توليد الباركود (Barcode Generation): كل طالب هينزل له باركود فريد مبني على الـ ID بتاعه (مثال: STUDENT-1002)، ونعرضه في شاشة الطالب أو نطبعه على الكارنيه.
