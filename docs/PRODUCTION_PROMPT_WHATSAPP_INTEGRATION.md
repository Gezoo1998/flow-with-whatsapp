# 📜 البرومبت الشامل لنقل ونشر نظام أتمتة الواتساب في السيستم الحقيقي (Production Master Prompt)

يقدم هذا المستند **برومبت جاهزاً ومفصلاً للنسخ المباشر** يتيح لك توجيهه لأي مساعد ذكاء اصطناعي لبناء ونقل نظام أتمتة الواتساب المتقدم بالكامل إلى نظامك الحقيقي، شاملاً شاشة التحكم المنفصلة، والتصفية حسب المجموعات والامتحانات/التسميعات، واستبعاد الطلاب غير المسجل لهم تقييم، إضافة الكروم V3، و**زر وضع التجربة الآمن الخالي من التعديل على قاعدة البيانات الحقيقية**.

---

## 📋 البرومبت الجاهز للنسخ (Copy-Paste Master Prompt)

> ✂️ **قم بنسخ النص الموجود داخل الصندوق التالي كما هو واستخدمه في مشروعك الحقيقي:**

```markdown
أريد منك إضافة وتكامل "نظام أتمتة الواتساب التلقائي المتقدم" (WhatsApp Automation Engine) داخل مشروعي، شاملاً شاشة تحكم واجهية كاملة ومنفصلة إضافة إلى "إضافة متصفح Chrome V3 مخصصة" للإرسال التلقائي بدون رسوم وبدون سيرفرات مدفوعة.

يرجى الالتزام بالمتطلبات والمعايير التالية بدقة:

---

### 1️⃣ أولاً: شاشة أتمتة الواتساب المنفصلة (Standalone WhatsApp Automation Page)
قم بإنشاء صفحة واجهة كاملة ومستقلة لأتمتة إرسال رسائل الواتساب (`WhatsAppAutomationView.tsx`) تحتوي على الخصائص التالية:

1. **اختيار نوع التقرير:**
   - خيار التحديد بين: **تسميع شفوي / درجات كويزات (Recitation)** أو **امتحانات رئيسية (Exams)**.

2. **تحديد المجموعة المستهدفة:**
   - قائمة منسدلة باختيار **المجموعة الدراسية (Group)** الخاصة بالطلاب المراد الإرسال لهم (أو اختيار جميع المجموعات).

3. **قائمة منسدلة للتسميع أو الامتحان المحدد:**
   - عند اختيار نوع التقرير والمجموعة، تظهر قائمة منسدلة تُمكّن المساعد من **اختيار التسميع المحدد أو الامتحان المحدد** الخاص بهذه المجموعات من القائمة.

4. **تصفية وحظر إرسال التقارير للطلاب غير المسجل لهم تقييم ⚠️ (Strict Rule):**
   - **قاعدة حتمية:** إذا كان الطالب ينتمي للمجموعة المختارة ولكن **لم يُسجّل له درجة/تسميع** في هذا التسميع أو الامتحان المحدد، يتم **استبعاده وتجاوزه تلقائياً** ولن يتم إرسال أي تقرير له.

5. **توجيه التقرير لهاتف ولي الأمر 📲:**
   - يتم توجيه جميع تقارير التسميعات والدرجات تلقائياً إلى **رقم هاتف ولي الأمر (`parentPhone`)** الخاص بالطالب.

6. **وضع التجربة الآمن 100% (In-Memory Test Mode Toggle) 🧪:**
   - أضف زراً مميزاً: **«🧪 تفعيل رقم التجربة 01022372501»**.
   - عند تفضيله، يتم توجيه جميع رسائل الواتساب في الذاكرة المؤقتة للشاشة للرقم `01022372501` لجميع الطلاب.
   - **⚠️ شرط أساسي وحازم:** عدم المساس بقاعدة البيانات الحقيقية (Postgres / MySQL / IndexedDB / Store) إطلاقاً، وتظل أرقام الطلاب الأصلية كما هي دون أي تعديل دائم.
   - إظهار بانر تنبيهي أصفر يوضح أن وضع التجربة مفعّل.
   - توفير زر أحمر لإيقاف وضع التجربة فوراً واستعادة الأرقام الحقيقية: **«🔴 إيقاف وضع التجربة (استعادة الأرقام الحقيقية)»**.

---

### 2️⃣ ثانياً: إنشاء إضافة متصفح Chrome (Chrome Extension Manifest V3)
قم بإنشاء مجلد مسمى `chrome-extension` في جذر المشروع يحتوي على الملفات التالية:

1. `manifest.json` (إصدار Manifest V3):
   - تعيين الصلاحيات: `tabs`, `scripting`, `storage`.
   - استخدام `exclude_matches: ["https://web.whatsapp.com/*"]` في `content-app.js` لعزل السكريبتات ومنع تكرار الحقن.

2. `background.js` (Service Worker):
   - إدارة طابور الطلاب (Queue).
   - توجيه التبويب للروابط بصيغة:
     `https://web.whatsapp.com/send?phone=PHONE&text=TEXT&centerflow_id=STUDENT_ID&centerflow_batch=BATCH_ID`
   - استخدام `batchId` فريد لتتبع كل دفعة إرسال.
   - تفعيل **مؤقت أمان قاطع (Safety Watchdog Timer - 14 ثانية)** لتخطي أي رقم غير مسجل في الواتساب تلقائياً ودون أن يعلق النظام.

3. `content-wa.js` (المحقون في موقع الواتساب `web.whatsapp.com`):
   - تطبيق تقنية **"Batch SessionStorage Lock"**: قراءة `studentId` و `batchId` وتخزين قفل في `sessionStorage` باسم `cf_sent_{studentId}_{batchId}` **قبل** النقر على زر الإرسال.
   - فحص خلو مربع الكتابة قبل النقر والتفريغ الفوري لمربع النص بعد النقر لمنع الإرسال المزدوج نهائياً.
   - استخدام `MouseEvent` موجه للنقر على زر الإرسال مرة واحدة فقط دون تكرار.
   - إرسال إشارة نجاح الإرسال `ITEM_SENT_SUCCESS` أو `ITEM_FAILED` إلى الخلفية.

4. `content-app.js` (المحقون في لوحة تحكم النظام):
   - إعلام تطبيق الـ Web بالتعرف على الإضافة وجاهزيتها.
   - نقل الإشارات والأوامر بين واجهة الصفحة وخلفية الإضافة.

---

### 3️⃣ ثالثاً: التحكم بشريط التقدم والـ Extension Integration
- اكتشاف تلقائي لوجود الإضافة وإظهار بادج الحالة (`إضافة Chrome متصلة وجاهزة 🧩✅`).
- زر رئيسي: **«بدء الإرسال الآلي بواسطة إضافة Chrome 🚀 (تلقائي 100%)»**.
- الاستماع اللحظي لإشارات الإرسال لتحديث حالة كل طالب في الجدول ببادج أخضر `تم الإرسال ✅` وتوثيق النشاط تلقائياً.
- شريط تقدم زمني مئوي (Progress Bar) يوضح المتبقي والمكتمل.
- نافذة تعليمات تثبيت الإضافة بـ `Developer Mode` في المتصفح.

يرجى تقديم الكود كاملاً ومنظماً ومتوافقاً مع مشروع Next.js و React.
```
